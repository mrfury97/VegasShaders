# Vegas Shaders material rules ([Shaders.PBR.MaterialRules] Enabled; docs/MATERIAL-RULES-PLAN.md).
# Picks how the object shaders treat a texture (metal or not, how rough) from its diffuse texture's path and live
# mesh/shader metadata (env-map flags, _m mask, specular/glossiness, emissive, mesh name). Edit freely; changes apply
# after a restart. A texture no rule covers looks exactly as with the rules off.
#
#   class    <name> metal=<off|guess|mask|full> strength=<0-1> rough=<min>-<max> reflections=<x> tint=<r>,<g>,<b> authored=<keep|replace> [sss=...]
#       metal: off = never metal; guess = colour + highlight-mask guess; mask = _m env mask is metal map (guess if none); full = all metal
#       strength: how metal it can get (replaces [Shaders.PBR.Metal] World / FirstPerson for these textures)
#       rough: the roughness range the normal map's highlight mask is spread over (leave out = global)
#       reflections: metal's reflection of its surroundings, times [Shaders.PBR.Metal] Reflections
#       tint: the class's colour in [Shaders.PBR.MaterialRules] DebugView
#       authored: keep (default) or replace (VanillaBridge). keep follows normal-alpha + mesh glossiness when present;
#                 replace uses rough= across the whole material
#   folder   <path prefix> <class> [final|fallback]
#                final = decided before keywords and protected from mesh-signal overrides
#                fallback = broad top-level bucket (yields to keywords, specific folders, pathwords, and live mesh signals)
#   keyword  <word in the file name> <class> [not=<word>,<word>]
#   pathword <word in a directory segment> <class> [not=<word>,<word>]
#   file     <full texture path> <class>
#   strip    <folder>   look through one folder level (e.g. "strip textures\nvdlc01")
# First match wins: file, final folder, keyword, folder, pathword, fallback folder, then live mesh/shader refinement.
