# Effects index

One folder per effect: its C++, `README.md` (what it does, inputs, settings, passes, edge cases, Vulkan, look; read it before changing the effect and update it in the same change), `defaults.toml` (its settings defaults: `tools/defaults_tool.py merge` builds the one defaults file from these; `check` verifies) and `SHADERS.txt` (its shader files, which stay in `src/hlsl/NewVegas`, the game's layout). The frame order is in `src/core/EffectChain.cpp`. Generated by `tools/effects_index.py`.
